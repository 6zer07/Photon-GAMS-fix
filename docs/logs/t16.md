# t16 — 2026-10-19

## 现象
挖方块时，破坏进度裂纹**被印到第一人称手臂上**（手臂挡在方块前时）。

## 根因
1. 覆盖层写在 `colortex3`，用 `alpha = 1/255` 编码（`overlay_id == 1`）；
2. `d4_deferred_shading.fsh` 对**每个像素**执行
   `albedo = 2.0 * albedo * overlays.rgb`，不判断该像素当前属于谁；
3. 覆盖层先写入（方块位置），手持物品后画只覆盖了 albedo（`colortex1`），
   `colortex3` 里的那份数据仍在 → 手臂像素被染上裂纹。

## 改动（1 文件，+8 / −4）
`shaders/program/gbuffers_all_solid.fsh`，仅 `PROGRAM_GBUFFERS_HAND` 分支：

| 位置 | 旧 | 新 |
| --- | --- | --- |
| out 声明 | `location 2 = translucent_clear` | `location 2 = overlay_clear`、`location 3 = translucent_clear` |
| RENDERTARGETS | `1,2,13` | `1,2,3,13` |
| 写入 | 只清 `translucent_clear` | 同时清 `overlay_clear` 与 `translucent_clear` |

`gbuffers_damagedblock.fsh` **保持不动**（继续写 `colortex3`），裂纹因此仍能正常显示。

## 验证
1. 挖方块：裂纹正常显示、进度正确；
2. 手臂挡在方块前：不再出现裂纹纹理；
3. 手持物品正常（不变透明、不丢像素）；
4. 附魔光效不受影响——Iris 下 glint 写的是 `colortex13`（`#ifdef IS_IRIS → RENDERTARGETS: 13`），
   与本版清 `colortex3` 不重叠；
5. 与 `t14` 相比只有 `gbuffers_all_solid.fsh` 一个文件不同。
