# t12 — 2026-09-10（打包）/ 2026-10-02（提交）

## 现象
1. 1.21+ 上透明贴图与粒子偏暗/偏亮/看不见；
2. 粒子作为不透明延迟几何体会丢混合 → 模组粒子异常、粒子穿透手持物品；
3. 发光粒子不发光（缺材质 mask）；
4. 一刀切丢弃“偏蓝”粒子，误杀模组物品粒子；
5. 半透明程序里 `get_directional_lightmaps()` 读取全局 `scene_pos`，屏幕空间导数算错。

## 根因
混合函数是 `ONE / ONE_MINUS_SRC_ALPHA`，程序却输出非预乘颜色并保留 `a = sqrt(a)` / `rgb / max(a, eps)`；
粒子走 `gbuffers_particles → gbuffers_all_solid`（延迟路径）；`colortex13` 合成时不做深度测试。

## 改动
20 个文件，**+257 / −81**（见 `docs/t12-code-changes.patch`）：预乘 alpha、粒子改走半透明程序 + 着色器内
遮挡剔除、粒子材质 27/47、蓝色粒子过滤加“下雨 + 露天”条件、参数化 directional lightmaps、新增
`PUDDLE_MODE` / `TRANSLUCENT_ALPHA` / `PARTICLE_OCCLUSION` / `USE_SEPARATE_ENTITY_DRAWS` /
`DITHERED_TRANSLUCENCY_FALLBACK`。
