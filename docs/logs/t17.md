# t17 — 2026-11-03

## 现象
用户反馈：**所有粒子效果都受「半透明贴图不透明度」影响**；他只希望咒翼灵骸这类本身带半透明贴图的**实体**
受影响。

## 根因（t12 引入、t13 放大）
* `t12` 把粒子从延迟路径改道到半透明程序，同时在 `gbuffers_all_translucent.fsh` 里加了

  ```glsl
  #if defined PROGRAM_GBUFFERS_ENTITIES_TRANSLUCENT || defined PROGRAM_GBUFFERS_PARTICLES || defined PROGRAM_GBUFFERS_PARTICLES_TRANSLUCENT || defined PROGRAM_GBUFFERS_BLOCK_TRANSLUCENT || defined PROGRAM_GBUFFERS_TEXTURED
  		if (material_mask != 102 && material_mask != 62) fragment_color.a *= TRANSLUCENT_ALPHA;
  #endif
  ```

  粒子因此被乘上该选项；
* `t13` 把公式改为 `mix(base_color.a, 1.0, TRANSLUCENT_ALPHA)`（默认 0.00、1.00 = 全不透明），
  于是调高该选项时**所有粒子**一起变实；
* 同一选项也作用在 `gbuffers_all_solid.fsh` 的抖动段（方块 + 实体），玻璃/冰/旗帜同样被带动。

## 改动（2 文件）
| 文件 | 改动 |
| --- | --- |
| `gbuffers_all_translucent.fsh` | 从条件里去掉 `PROGRAM_GBUFFERS_PARTICLES` 与 `PROGRAM_GBUFFERS_PARTICLES_TRANSLUCENT` |
| `gbuffers_all_solid.fsh` | 抖动分流：实体用 `mix(alpha, 1.0, TRANSLUCENT_ALPHA)`；方块用固定的 `alpha * 0.75` |

## 结果
| 对象 | 受该选项控制 |
| --- | --- |
| 实体的半透明贴图（咒翼灵骸、模组翅膀/布料） | ✅ 是 |
| 粒子（火焰、烟雾、仪式粒子…） | ❌ 否 |
| 方块（玻璃、冰、旗帜） | ❌ 否（回到固定行为） |

## 验证
1. 把选项拉到 1.00：粒子不应变实；咒翼灵骸应变实；
2. 玻璃/冰/旗帜不受滑块影响；
3. 拉回 0.00：实体回到最透，粒子/方块不变；
4. 与 t16 相比只有 2 个文件不同。
