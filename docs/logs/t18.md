# t18 — 2026-11-18

> 本 t18 是 `t17` 之后的正式版。更早那批 `t18`–`t21` 是失败的尝试（从未发布；构建树已删除，仅保留
> `t20`/`t21` 的 zip 供复盘），与本版无关。

## 现象
开启 Distant Horizons（环境：DH 3.3.3）后，**水面在镜头移动时抖动**；官方 Photon 1.4 无此问题。

## 定位过程（三个候选，前两个被排除）
| 候选 | 做法 | 结果 |
| --- | --- | --- |
| ① TAA 重投影 | DH 下半透明像素（水面）的速度只取本像素 MC 深度，不参与「5 点邻域最近」与 MC/DH 二选一 | **无效**，仍抖 |
| ② `border_fog` | DH 下不做 alpha 淡出（`dhRenderDistance` 随 DH 自适应 LOD 距离逐帧变化） | 首版在 DH 分支提前 `return 1.0`，导致 `fog` 未定义、`deferred4.fsh` 编译失败；修好后**无效** |
| ③ **水面 TBN** | DH 下顶面使用硬编码朝上的 TBN 矩阵 | **修好了** ✅ |

## 根因
水面纹理由 `world_pos * tbn` 采样。t17 在 DH 下用 `get_tbn_matrix(tbn[2])`——从**顶点法线**现算切线空间。
DH 的 LoD 水面与本包水面相接处，两边顶点法线有细微差异，于是相邻像素的切线空间不一致，纹理采样位置在像素间
跳变；镜头移动时表现为整片水面抖动。

## 改动（1 文件）
`shaders/program/gbuffers_all_translucent.fsh`：

```glsl
#ifdef DISTANT_HORIZONS
	mat3 tbn = get_tbn_matrix(tbn[2]);
	if (abs(tbn[2].y) > 0.99) {          // 顶面
		tbn = mat3(vec3(1.0, 0.0, 0.0), vec3(0.0, 0.0, 1.0), vec3(0.0, 1.0, 0.0));
	}
#endif
```

依据：Photon 1.4 在 `gbuffers_all_translucent.fsh` 第 441-451 行就是这么写的，注释明确说明
"the same for LoD water and regular water"。
