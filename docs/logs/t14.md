# t14 — 2026-10-17

## 现象
反馈截图：相较 GAMS 原版，**水体似乎不受雾气遮挡**——远处水面清晰、颜色不变，而周围地形已被雾洗白。

## 根因
`t12` 把 translucent 程序结尾从“直通 + un-premultiply”改成预乘时，连带删掉了

```glsl
fragment_color.a *= border_fog(position_scene, direction_world);
```

`border_fog()`（`include/fog/simple_fog.glsl`）返回 alpha 保留率（近处 ≈1、远处趋 0），负责让远处
半透明表面淡出并融入雾中。缺了它，远处水面始终以高 alpha 覆盖在雾化场景上。

## 改动（1 文件，+5 / −0）
`gbuffers_all_translucent.fsh`：在预乘**之前**恢复 alpha 衰减。

```glsl
fragment_color.a *= border_fog(position_scene, direction_world);

#ifdef PREMULTIPLIED_ALPHA
	fragment_color.rgb *= fragment_color.a;
#endif
```

## 等价性
`common_fog(view_dist, sky)` 只接收距离、不读 alpha，所以“预乘前衰减 alpha”与上游“雾之后衰减 alpha”
数学等价：最终像素均为 `scene·(1−a) + a·C·T + S`，其中 `a` 已含 border fog。

## 影响面
远处水面/冰/玻璃/旗帜随距离淡出（恢复原版行为）；近处水面基本不变；
**粒子**也会淡出（`t12` 把粒子搬进了同一程序），若不希望可按 `material_mask == 27/47` 跳过。

## 验证
`docs/t14-code-changes.patch` 应用到 `t13` 后即为本版；链式校验 `t12 + t13 + t14 == t14` 通过。
