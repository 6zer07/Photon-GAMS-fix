# t13 — 2026-10-17

## 现象
1. 粒子在雨天/雾中出现**条纹**；
2. 发光实体**整只变橙**、丢失原色；
3. 不只是发光实体，**任何站在满方块光下的实体**都会被染橙。

## 根因
遮挡判据用原始窗口深度（`depth1 < gl_FragCoord.z - 1e-5`），近乎共面时逐像素翻转；硬编码自发光材质
（mask 39 熔岩 / 40 中橙 / 金色）执行 `material.albedo = float(albedo) * vec3(常量色)` 把颜色整体替换；
`gbuffers_all_solid.vsh` 的火焰实体兜底写成 `if (light_levels.x > 0.99) material_mask = 40;`。
