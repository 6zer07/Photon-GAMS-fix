# 逐版本开发日志

## 规则

**每次改动 = 一个新版本号 + 一份日志 + 一条 CHANGELOG 条目 + 一个提交**，四者一一对应。

* 版本号单调递增，**不在已发布的版本号上就地加改动**（`t13` 曾因此把水雾修复一起上传，后来拆成 `t14`）；
* 只动注释/文档也要记日志，并注明“不改变行为”；
* 产物 zip 记录 SHA256，仓库状态记录 tree SHA，便于核对。

## 模板

```markdown
# t<NN> — <YYYY-MM-DD>

## 现象
## 根因（文件 + 行号 + 旧代码 → 新代码）
## 改动（表格：文件 / 行 / 旧 → 新）
## 验证（自测点 + 补丁应用校验）
## 产物（zip / 补丁 / tree SHA）
## 关联记录
```
