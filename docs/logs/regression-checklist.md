# 回归自测清单

> 每次改动后跑一遍。每项标注引入版本与**失效时的典型现象**。

## A. 粒子与半透明（t12 / t13 / t14）

| # | 测试 | 版本 | 失效现象 |
| --- | --- | --- | --- |
| A1 | 拿手持物品走到营火/火把前 | t12 | 火/烟粒子画在手上 |
| A2 | 水中或雨里抬头 | t12 | 水/雨穿透手持物品 |
| A3 | Ars Nouveau 仪式粒子 | t12 | 粒子缺失或变不透明 |
| A4 | 雨天露天地面 | t12 | 地面蓝色水花（应隐藏）/ 水龙头水滴（应保留） |
| A5 | 贴近墙面看粒子 | t13 | 粒子出现条纹 |
| A6 | 雨天/雾天看远处水面 | t14 | 水面清晰、不吃雾 |
| A7 | 玻璃 / 冰 / 旗帜 | t13 | 透明度不符合「半透明贴图不透明度」设定 |

## B. 实体与自发光（t13）

| # | 测试 | 失效现象 |
| --- | --- | --- |
| B1 | 满方块光下的普通生物 | 整只被染成橙色 |
| B2 | 岩浆 / 火把 / 发光矿石 | 整片纯橙、丢失纹理 |
| B3 | 火焰实体（`entity_flame`） | 完全不发光 |
| B4 | 带半透明贴图的实体（咒翼灵骸） | 几乎看不见，或像不透明贴图 |

## C. 覆盖层（t16）

| # | 测试 | 失效现象 |
| --- | --- | --- |
| C1 | 挖方块时看裂纹 | 裂纹完全不显示（走了写 colortex0 的分支） |
| C2 | 挖方块时手臂挡在方块前 | 手臂被印上裂纹 |
| C3 | 挖方块时裂纹纯黑 | 上游 `#ifdef IS_IRIS` 分支在本包无效 |
| C4 | 手持附魔武器 | 光效消失（glint 走 colortex13，注意与手持清除的先后） |
| C5 | 模组覆盖层（Create 选择框） | 发黑或不可见 |

## D. 加载（换包必查）

| # | 检查 | 失效现象 |
| --- | --- | --- |
| D1 | 光影能加载、无错误弹窗 | `Unexpected token ';'` / `not cancellable` |
| D2 | 材质页选项可拖动 | 选项解析失败（`#define` 被写坏） |
| D3 | 日志无 `Failed to create shader rendering pipeline` | 某个 program 编译失败 |

> `#endif without #if` 是 Photon 自带噪声，所有版本都有，不致命。
> `The call m_166612_ is not cancellable` 等价于“某个 shader 编译失败”（Oculus 1.8.0 的 Mixin 伪装了它）。
